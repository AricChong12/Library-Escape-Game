# Library-Escape-Game

Library Escape Game, developed using MIPS Assembly language, this program demonstrates core low-level programming concepts such as decision-making structures, loops, and function calls. Created as part of a team project, it highlights our collective ability to work collaboratively while mastering the fundamentals of assembly-level logic and control flow. This experience deepened our understanding of how high-level constructs are implemented at the machine level and strengthened our problem-solving skills in a system-level programming environmen
